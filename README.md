# MY-VSCODE-THEME-

I like to have my own theme on VS Code, so I make my own based on my preferences. 

Here is the setting that I used :
[Setting](./the_settings/settings.json)

How to apply this setting?
1. Open the Command Palette or use a shortcut: Ctrl + Shift + P(for Windows) or Cmd + Shift + P(for Mac)
2. Select Open User Settings (JSON)
3. Copy my settings.json and paste it into your own settings.json
4. Feel free to change the color by changing the HEX Color Code.
